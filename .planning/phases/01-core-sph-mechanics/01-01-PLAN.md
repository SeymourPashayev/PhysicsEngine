  <name>Task 1: Create SPHSolver class</name>
  <files>src/Physics/SPHSolver.hpp, src/Physics/SPHSolver.cpp, Makefile</files>
  <action>
Create SPHSolver class that owns the SPH computation pipeline.

**SPHSolver.hpp:**
- Include Particle2D.hpp, Octree2D.hpp, SPHKernel.hpp, Constants.hpp
- Class SPHSolver with:
  - Constructor taking smoothing length (h) parameter
  - `void Initialize(float smoothingLength)` - calls SPHKernel::Initialize
  - `void ComputeDensityPressure(std::vector<Particle2D*>& particles, Octree2D* octree)` - computes density and pressure for all particles
  - `void ComputeForces(std::vector<Particle2D*>& particles, Octree2D* octree)` - placeholder for Plan 02
- Private members:
  - `float smoothingLength` - kernel radius
  - `float restDensity` - from Constants.hpp (REST_DENSITY = 1000.0f)
  - `float stiffness` - for Tait equation (use 1000.0f as gas constant B)
  - `float gamma` - Tait exponent (use 7.0f for water)

**SPHSolver.cpp:**
- Implement Initialize: store smoothingLength, call SPHKernel::Initialize(h)
- Implement ComputeDensityPressure:
  1. For each particle:
     a. Query octree for neighbors within smoothingLength: `octree->findNeighbors(neighbors, particle, smoothingLength)`
     b. Sum density: `density = sum(mass_j * Poly6(|r_i - r_j|))` for all neighbors including self
     c. Compute pressure via Tait equation: `pressure = stiffness * (pow(density/restDensity, gamma) - 1.0f)`
     d. Clamp pressure to >= 0 (no negative pressure)
     e. Store in particle->density and particle->pressure

**Makefile update:**
- Add `./src/Physics/SPHSolver.cpp` to the compilation line alongside other Physics files

Use existing SPHKernel::Poly6(Vec2 r) for kernel evaluation. The Vec2 overload calls Magnitude internally.
