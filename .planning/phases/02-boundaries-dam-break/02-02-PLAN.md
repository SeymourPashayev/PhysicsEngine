```cpp

#include "../System.hpp"

class DamBreak : public System {

    DamBreak();
    ~DamBreak() override;
};

#endif
```

Implement DamBreak.cpp following research document (02-RESEARCH.md "Dam Break Fluid Initialization"):
1. In constructor, enable required physics toggles:
   - FLUID_DYNAMICS_ENABLED = true (for SPH)
   - INTEGRATION_ENABLED = true
   - GRAVITY_ENABLED = true
   - SCREEN_COLLISION_ENABLED = false (disable - using boundary particles instead)
   - All other toggles false

2. Calculate parameters:
   - particleSpacing = 4.0f (matches existing particle size)
   - particleMass = REST_DENSITY * particleSpacing * particleSpacing (from Constants.hpp)
   - containerWidth = Graphics::Width()
   - containerHeight = Graphics::Height()
   - damWidth = containerWidth * 0.25f (1/4 width)
   - damHeight = containerHeight * 0.66f (2/3 height)

3. Create boundary particles:
   - Call CreateRectangularContainer(particles, containerWidth, containerHeight, particleSpacing, particleMass)
   - This creates bottom/left/right walls with 3 layers, top open

4. Create fluid column on left side (regular grid, zero initial velocity):
   - Start at offset (3 * particleSpacing, 0) to avoid overlap with left wall
   - Regular grid: nested loops for x in [offset.x, offset.x + damWidth) and y in [0, damHeight)
   - Each particle: new Particle2D(Vec2(x, y), particleMass), set isBoundary=false, velocity=Vec2(0,0), color=0xFF4499FF (blue fluid)
   - Add to particles vector

5. Set boundary particle color to distinguish visually:
   - After CreateRectangularContainer, iterate particles and set color=0xFF333333 (dark gray) for particles where isBoundary==true

Modify Application.cpp Setup method to instantiate DamBreak instead of current scene (replace line that creates WaterDam or other scene with `new DamBreak()`).

Add DamBreak.cpp to Makefile OBJS after WaterDam.o.

Rationale: Dam break is standard SPH benchmark. Fluid column on left creates gravitational potential energy that converts to kinetic energy during collapse, demonstrating pressure forces, wave propagation, and boundary containment.
